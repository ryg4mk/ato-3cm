# あと3センチ。

**ONE TAKE GAME #002**

画面下を左右に往復しながら360°回転する車を、タイミングを見て上スワイプ1回で発射し、上部に並ぶ6台分の駐車スペースのうち唯一空いている枠へ駐車するスマートフォン向けブラウザゲームです。

## 遊び方

- 車は画面下を左右に往復しながら回転し続けます。
- タイミングを見て画面を上方向へスワイプすると、車が1回だけ発射されます。
- 発射時の横方向の速度、車体角度、角速度がそのまま結果に影響します。
- 空いている1枠へ、できるだけきれいに停めてください。
- 結果は `PERFECT!` / `PARKING!` / `あと○cm！` / 失敗メッセージで表示されます。
- BEST記録はブラウザの `localStorage` に保存されます。

## 操作方法

- スマートフォン: 上スワイプ1回
- PC: マウスで上方向へドラッグ1回

スワイプの長さや斜め成分で発射力・発射方向は変化しません。調整するのは発射するタイミングだけです。

## 公開方法

`index.html` / `style.css` / `game.js` / `README.md` を同じディレクトリへ置くだけで動作します。npm、ビルド工程、バックエンドは不要です。

CSS・JavaScriptは相対パスで参照しているため、GitHub Pagesのプロジェクトサブパスへそのまま配置して公開できます。

外部画像、外部素材、外部ライブラリは使用していません。ゲーム内グラフィックはすべてHTML Canvas APIによるコード描画です。
